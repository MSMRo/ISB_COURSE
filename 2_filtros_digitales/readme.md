# Módulo 2: Filtros digitales

Este módulo contiene notebooks y scripts para estudiar el filtrado de señales en tiempo discreto y observar sus efectos tanto en el dominio del tiempo como en el de la frecuencia.

## Contenidos

- Transformada discreta de Fourier (DFT) y respuesta en frecuencia.
- Diseño y aplicación de filtros FIR e IIR, incluidos ejemplos con SciPy.
- Filtros pasa-bajas y otros tipos de respuesta, junto con ejemplos de filtros RC.
- Comparación de señales originales y filtradas mediante gráficas y espectros.
- Lectura de datos de ECG/EMG y aplicación de coeficientes de filtro.

Explora los archivos `.ipynb` de esta carpeta para seguir los ejemplos paso a paso. `Codigo_filtros.py` reúne funciones para leer muestras y coeficientes, aplicar un filtro y visualizar la señal y su FFT.
