# Módulo 1: Señales y sistemas

Este módulo reúne materiales introductorios sobre señales de tiempo continuo y discreto, además de herramientas para describir sistemas lineales.

## Contenidos

- **Señales básicas** ([carpeta](1_1_señales_basicas/)): señales senoidales, escalón unitario y rampa, con ejemplos y representaciones gráficas.
- **Sistemas** ([carpeta](1_2_systems/)): introducción a los dominios \(s\) y \(z\), análisis de polos y criterios de estabilidad.

Los notebooks están organizados por tema dentro de cada carpeta. En `1_2_systems/` también se incluye `util_graphs.py` con utilidades de graficación.
