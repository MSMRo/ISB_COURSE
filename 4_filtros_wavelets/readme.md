# Módulo 4: Filtros wavelet

Este módulo explora el análisis de señales mediante wavelets y la transformada wavelet discreta (DWT).

## Contenidos

- Construcción de señales para los ejemplos de análisis.
- Descomposición con DWT en los notebooks `2_filtros_dwt.ipynb` y `3_filtros_dwt2.ipynb`.
- Análisis complementario de frecuencia y filtrado en `4_filtro_wavelet.ipynb`.

Ejecuta los notebooks en esta carpeta para revisar los ejemplos y comparar las representaciones obtenidas.
