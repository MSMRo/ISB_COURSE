# Módulo 3: Filtros adaptativos

Los materiales de este módulo presentan métodos que ajustan sus parámetros a partir de la señal observada, con ejemplos de filtrado y predicción.

## Contenidos

- Algoritmo LMS (`LMS_filter.ipynb`) y adaptación de un filtro a una señal.
- Filtro de Wiener (`filtro_wiener1.ipynb`).
- Estimación y predicción de señales con Kalman, en los notebooks de la sesión 10.

Abre los notebooks de esta carpeta en orden según el tema que quieras estudiar; cada uno contiene sus propios ejemplos y visualizaciones.
