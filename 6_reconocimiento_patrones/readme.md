# Módulo 6: Reconocimiento de patrones

Esta carpeta contiene experimentos de generación, segmentación y clasificación de señales ECG, además de ejemplos de preparación de modelos para su uso en dispositivos.

## Contenidos

- Generación de señales ECG para distintas clases y preparación de conjuntos de datos.
- Segmentación de ECG mediante aprendizaje profundo.
- Entrenamiento y evaluación de modelos LSTM en varios notebooks.
- Conversión de modelos o bases de datos a TensorFlow Lite (`Crear_modelo_tflite.ipynb` y `DB2TFLITE.ipynb`).
- Ejemplos de normalización y revisión de estadísticas con media y desviación estándar.

Los notebooks son experimentos independientes; consulta sus primeras celdas para conocer los datos, paquetes y archivos requeridos antes de ejecutarlos.
