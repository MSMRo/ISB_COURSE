# Módulo 5: Extracción de características

Este módulo trabaja con señales biomédicas como entrada para etapas posteriores de análisis y clasificación.

## Contenidos

- Lectura y exploración de registros EMG de PhysioNet (`EMG_physionet_01.ipynb`).
- Simulación de señales ECG con NeuroKit2 (`señales_EKG.ipynb`).
- Análisis de señales EMG mediante ventanas deslizantes (`sliding_windows.ipynb`).

Los notebooks muestran ejemplos de preparación y segmentación de las señales. Revisa las celdas iniciales de cada notebook para identificar los datos de entrada que necesita.
